## Non-ok items, most serious first

1. **Line 545, StateMem ablation mischaracterised.** 0.233 → 0.208 is correct, but it ablates the *recompute guidance prompt*, not per-unit visibility. The flag-producing component (dependency propagation) has mixed ablation results (0.222 Qwen; 0.373 > 0.363 DeepSeek), and the authors call the margins an upper bound.
2. **Lines 485 and 554, "same rule as MemState's abort-on-postcondition-violation".** [P1] Algorithm 1 aborts the *whole transition* when a *policy postcondition* fails. No P1 policy forbids empty overwrites. Parse failure is input validation, not a postcondition. The MemState repo has no postcondition check at all (alignment.md:86, :104). Analogous, not the same rule. The wording also conflicts with line 552's own granularity caveat.
