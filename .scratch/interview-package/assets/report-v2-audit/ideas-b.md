## Non-`ok` items, most serious first

1. **Line 623, Zep authority is wrong.** In Zep the *episode* tier is the non-lossy ground truth and entities and facts are extracted from it (P4:53; Graphiti README "Episodes … the ground truth stream"). No source says the entity level "wins conflicts" or that the other levels are rebuilt from it. The same line also contradicts itself: topics "resemble communities" (the top tier), yet "MemState promotes the middle tier".
2. **Lines 576–577, misattributed.** Per-tenant salience isolation and erasure of derived salience and provenance traces are [P1]'s own Privacy and Multi-Tenancy first targets (P1:361–365), not "added by this review". This also conflicts with report line 556.
3. **Line 581, Kuzu.** Graphiti still ships its Kuzu driver, deprecated, not just "older versions". This also affects how robust the Graphiti-on-Kuzu baseline at line 596 is.
4. **Line 641, the 20.2 figure.** It matches MAFBench's prose, but MAFBench's own Table 10 shows 20.2 is the SF *average*; single-hop is 36.0 and multi-hop 4.5 (P6:372). Cite the table values.
5. **Line 587, Graphiti tenant isolation.** "Covered" is overstated: `group_id` is an unauthenticated partition, and Graphiti has no salience to isolate.
6. **Line 647, C3 diagnosis.** "Multi-hop forgetting below 5 is a C3 failure" is stated as fact, but it is an interpretation the report itself says answer-level scores cannot confirm (line 650).
7. **Line 617, promotion trigger.** [P1]'s trigger is accumulated knowledge or references (P1:273). The "own lifecycle" criterion is MemState's code guidance (topic.py:28-30).
8. **Line 591, "the graph only grows".** Graphiti has `remove_episode`; what is missing is relevance-driven decay.
9. **Line 602, closed-pool grading.** It does not "avoid" judge sensitivity: a judge still maps 72% of answers (SMB:548).
10. **Line 622, LightRAG high-level keys.** They match relations indexed by theme keywords, not "themes" directly (arXiv 2410.05779 §3.1–3.2).
11. **Line 570, "first target".** P1:347 names three first targets, so labelling only the concurrency item is misleading.
12. **Line 606, unattributed.** The three-level ground truth is [P1]'s own specification (P1:351) and should be credited.
13. **Summary item 10 (line 37).** "every evaluated framework" should be "every memory architecture evaluated": SF was run on four frameworks, not nine.

No `needs-run` items: this slice makes no runtime claims about MemState.
